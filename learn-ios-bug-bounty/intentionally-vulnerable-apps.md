# ⚙️ Intentionally Vulnerable Apps

Install these on a test device and try the techniques from the writeups. Breaking a real app is easier once you have already broken a lab.

| Name | Description | Link |
| --- | --- | --- |
| Damn Vulnerable iOS App (DVIA v2) | Covers common iOS issues like insecure storage, jailbreak detection and IPC | [GitHub](https://github.com/prateek147/DVIA-v2) |
| OWASP iGoat-Swift | Vulnerable iOS app built for learning, with exercises | [GitHub](https://github.com/OWASP/iGoat-Swift) |
| Security Compass iPhone Labs | Hands-on iOS labs with guided exercises | [Website](https://securitycompass.github.io/iPhoneLabs/) |
| OWASP MASTG app | App used in the MASTG iOS exercises | [MASTG](https://mas.owasp.org/MASTG/apps/ios/MASTG-APP-0024/) |
