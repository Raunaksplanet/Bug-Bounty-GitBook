# 🎓 Certifications

Certifications will not make you good at iOS testing, but they give you a structured syllabus and a deadline. Do the labs first, then decide.

- [Certified Mobile Pentester (CMPen) Android](https://pentestingexams.com/certifications/professional/certified-mobile-pentester-cmpen-android/): Android version, useful if you test both platforms.
- [Certified Mobile Pentester (CMPen) iOS](https://pentestingexams.com/certifications/professional/certified-mobile-pentester-cmpen-ios/): iOS focused certification.
- [eMAPT by INE](https://ine.com/security/certifications/emapt-certification): mobile application penetration testing cert.
- [PMPA by TCM Security](https://certifications.tcm-sec.com/pmpa/): practical mobile pentesting cert.
