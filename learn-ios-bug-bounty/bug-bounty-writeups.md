# 📰 Bug Bounty Writeups

Writeups where the bug was found in an iOS app or the iOS side of a product. Read the recon steps more than the payload, that is where most of the value is.

- [Attacking iOS: recon and exploitation guide](https://anontriager.medium.com/attacking-ios-elite-recon-and-exploitation-guide-for-bug-bounty-hunters-0c67e2160484): good starting point for bug bounty work.
- [Bypassing Screen Time limits on macOS](https://1-day.medium.com/your-kid-might-be-bypassing-screen-time-app-limits-on-macos-using-this-trick-0fed8225bf79): macOS rather than iOS, but the same kind of logic bug.
- [iOS penetration testing part 1](https://p4n7h3rx.medium.com/ios-penetration-testing-part-1-beginners-guide-8d6e6b189f5d): beginner guide.
- [iOS penetration testing part 2](https://p4n7h3rx.medium.com/ios-penetration-testing-part-2-advanced-guide-e769cbafcf04): advanced follow up.
- [iOS recon: hunting endpoints inside IPA files](https://meetcyber.net/ios-recon-hunting-endpoints-inside-ipa-files-1d495da38f5b): what to pull from an IPA before testing.
- [Start your first iOS application pentest](https://kishorbalan.medium.com/start-your-first-ios-application-pentest-with-me-part-1-1692311f1902): part 1, beginner friendly.
