# 👋 Welcome to Biscuit Security

Biscuit Security is my security research and bug bounty hub. I use it to collect the resources I actually use: writeups, testing notes, tools and link lists for Android, iOS, web, API and thick-client security. Everything here is free to read and meant to save you the hours I spent looking for the same links.

I post videos on [YouTube](https://www.youtube.com/@BiscuitSecurity) and write longer posts on [biscuitsecurity.com](https://biscuitsecurity.com).

## About Raunak Gupta

I'm Raunak Gupta, also known as Biscuit. I'm a security researcher and bug bounty hunter, and I run Biscuit Security. My main focus is mobile and thick-client security, along with web and API testing. I've reported enough valid bugs to cross 100+ Hall of Fame entries, and I teach what I learn on Udemy, YouTube and Medium.
